# React + JavaScript Interview Preparation

A personal learning dashboard for tracking progress while preparing for JavaScript, React, frontend development, and interview-related topics.

![Dashboard Preview](https://raw.githubusercontent.com/Ashish-onGit/React-JS-Interview-Roadmap/main/preview.png)

## 🚀 Key Features

- **Interactive Roadmap**: Comprehensive curriculum covering 27 categories across JavaScript, React, Browser APIs, TypeScript, Architecture, Testing, CI/CD, and Projects.
- **Progress Tracking**: Granular completion tracking at the subtopic and topic levels with dynamic calculation across sections, categories, and overall roadmap.
- **Local Persistence**: Automatic synchronization with `localStorage` so your preparation progress is never lost.
- **Global Search**: Instant case-insensitive search across all modules with breadcrumb navigation (`Ctrl + K`).
- **Collapsible Sidebar & Desktop Toggle**: Full control over your workspace with desktop sidebar toggling (`Ctrl + B`) and an expandable progress section.
- **Mobile Responsive**: Adaptive navigation bar, touch-friendly items, and slide-out mobile drawer.
- **Zero Backend**: Lightweight client-side application built with pure React state and modern web standards.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router v6](https://reactrouter.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Storage**: Browser `localStorage`

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Ashish-onGit/React-JS-Interview-Roadmap.git
   cd React-JS-Interview-Roadmap
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
